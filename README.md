# ☕ Coffee Orders Data Analysis Project

## 📊 Project Overview
This project focuses on analyzing coffee sales data to uncover meaningful insights related to customer behavior, product performance, and sales trends.  

The dashboard is built using **Microsoft Excel** and includes interactive visualizations to support data-driven decision-making.

## 🔍 Key Insights
- 🇺🇸 United States generates the highest revenue  
- 📈 Sales peak during specific months  
- ☕ Arabica coffee shows strong performance  
- 💳 Loyalty card users contribute significantly to revenue  
- 👥 Top customers identified for targeted marketing
